# 代码编辑器测试场景

## 功能概述

这个测试场景演示了Godot 4.x中`CodeEdit`控件的各种功能，包括：

### 核心功能
- **语法高亮**: 支持多种编程语言的语法高亮
- **代码提示**: 自动补全和智能提示
- **多主题支持**: 默认、深色、浅色三种主题
- **实时统计**: 显示行数、字符数、单词数等统计信息

### 支持的编程语言
- **GDScript** - Godot原生脚本语言

### 编辑器功能
- 行号显示
- 代码折叠
- 小地图导航
- 自动换行
- 字体大小调节
- 光标位置显示

## 使用方法

### 基本操作
1. 在代码编辑器中输入或编辑代码
2. 使用右侧控制面板调整编辑器设置
3. 观察底部信息栏的实时统计

### 快捷键
- `F1` - 切换主题（默认/深色/浅色）
- `F2` - 重新加载GDScript示例
- `F3` - 切换行号显示
- `F4` - 切换小地图显示
- `F5` - 切换自动换行
- `F6` - 触发代码补全

### 代码补全操作
- `F6` 或 `Tab` - 手动触发代码补全
- `↑/↓` - 在补全列表中导航
- `Enter` - 确认选择
- `Tab` - 确认选择
- `Esc` - 取消补全

### 控制面板选项
- **主题设置**: 选择编辑器的颜色主题
- **字体大小**: 调整代码字体大小（8-32px）
- **显示选项**: 控制行号、小地图、自动换行的显示

## 技术实现

### 语法高亮
使用`CodeHighlighter`资源实现：
- 关键字高亮（青色）
- 内置函数高亮（橙色）
- 字符串高亮（黄色）
- 注释高亮（灰色）

### 代码提示
- 通过`code_completion_enabled`启用自动补全功能
- 支持多种编程语言的关键字和函数提示
- 按`F6`键或`Tab`键手动触发代码补全
- 显示IDE风格的下拉补全列表
- 支持键盘导航（上下箭头键）
- 根据当前选择的语言提供相应的补全建议
- 智能识别当前单词并提供上下文相关的建议
- 自动插入补全文本到编辑器中

### 主题系统
动态切换编辑器的颜色主题：
- 背景色
- 文字颜色
- 行号颜色
- 选择区域颜色

## 扩展功能

### 添加新语言支持
1. 在`code_examples`字典中添加新的语言示例
2. 添加对应的语言选择器
3. 根据需要调整语法高亮规则

### 自定义主题
可以通过修改`_apply_*_theme()`函数来创建自定义主题。

### 增强代码提示
可以通过扩展`_setup_code_completion()`函数来添加更多代码提示选项。

## 注意事项

1. 代码提示功能在Godot 4.x中主要通过语法高亮器提供
2. 某些高级功能可能需要额外的插件或扩展
3. 性能可能受到代码量和复杂度的影响
