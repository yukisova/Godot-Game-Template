# 视线边缘模糊着色器

## 概述
这是一个用于模拟角色视线的边缘模糊着色器，可以创建从中心清晰到边缘模糊的视觉效果，常用于：
- 模拟真实的人眼视觉特性
- 创建聚焦引导效果
- 增强游戏沉浸感
- 视觉层次设计

## 文件列表
- `视线边缘模糊.gdshader` - 着色器主文件
- `视线边缘模糊材质.tres` - 着色器材质资源
- `test2.tscn` - 演示场景

## 着色器参数

### CanvasLayer变换参数
- **canvas_scale** (Vector2): CanvasLayer的缩放系数
- **canvas_offset** (Vector2): CanvasLayer的偏移量

### 视线中心参数
- **vision_center** (Vector2): 视线焦点中心位置 (0.0-1.0)
- **focus_radius** (float): 清晰焦点区域半径 (0.0-1.0)
- **blur_falloff** (float): 模糊衰减强度 (0.1-3.0)

### 模糊参数  
- **blur_strength** (float): 模糊强度 (0.0-0.02)
- **blur_samples** (int): 模糊采样数量 (3-12)

### 渐变参数
- **edge_softness** (float): 边缘柔和度 (0.0-1.0)  
- **vignette_strength** (float): 渐晕强度 (0.0-1.0)
- **vignette_color** (Color): 渐晕颜色

### 动态效果参数
- **use_animation** (bool): 启用动画效果
- **animation_speed** (float): 动画速度 (0.1-3.0)
- **animation_intensity** (float): 动画强度 (0.0-0.2)

## 使用方法

### 1. 基础使用
```gdscript
# 获取着色器材质
var vision_material = $VisionOverlay.material as ShaderMaterial

# 设置视线中心
vision_material.set_shader_parameter("vision_center", Vector2(0.5, 0.5))

# 调整焦点半径
vision_material.set_shader_parameter("focus_radius", 0.3)

# 设置CanvasLayer变换
vision_material.set_shader_parameter("canvas_scale", Vector2(1.0, 1.0))
vision_material.set_shader_parameter("canvas_offset", Vector2(0.0, 0.0))
```

### 2. 跟随角色视线 (基于CanvasLayer坐标系)
```gdscript
func update_vision_center():
    var vision_overlay = $CanvasLayer/VisionOverlay
    var overlay_size = vision_overlay.size
    var char_pos = character.global_position
    
    # 转换为CanvasLayer的UV坐标
    var center_offset = Vector2(overlay_size.x * 0.5, overlay_size.y * 0.5)
    var uv_x = (char_pos.x + center_offset.x) / overlay_size.x
    var uv_y = (char_pos.y + center_offset.y) / overlay_size.y
    
    vision_material.set_shader_parameter("vision_center", Vector2(uv_x, uv_y))

# 更新CanvasLayer变换参数
func update_canvas_transform():
    var canvas_layer = $CanvasLayer
    var scale = canvas_layer.transform.get_scale()
    var origin = canvas_layer.transform.get_origin()
    
    vision_material.set_shader_parameter("canvas_scale", scale)
    vision_material.set_shader_parameter("canvas_offset", origin / get_viewport().get_visible_rect().size)
```

## 性能优化建议

1. **采样数量**: 降低 `blur_samples` 可提高性能
2. **模糊强度**: 适中的 `blur_strength` 既能达到效果又保证性能
3. **动态更新**: 避免每帧都更新着色器参数
4. **层级管理**: 使用 CanvasLayer 确保正确的渲染顺序

## 技术实现

### CanvasLayer坐标系
使用 `UV` 坐标而非 `SCREEN_UV`，确保效果基于CanvasLayer的视图而非整个窗口视图，支持CanvasLayer的变换、缩放等。

### 屏幕后处理
使用 `hint_screen_texture` uniform 获取屏幕内容，实现真正的后处理效果，兼容Godot 4.x版本。

### 高斯模糊算法
使用多采样高斯模糊实现平滑的边缘过渡效果，支持可调节的采样半径和权重分布。

### 径向渐变
基于距离的径向渐变计算，支持椭圆形焦点区域和自定义衰减曲线。

### 性能优化
- 边界检查避免无效采样
- 权重归一化确保颜色一致性  
- 动态参数减少不必要的计算
