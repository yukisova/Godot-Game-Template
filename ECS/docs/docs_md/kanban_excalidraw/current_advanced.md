## 聚光灯的游戏设计

- [ ] 目前已经确定，游戏的主题是索拉的世界的第二代勇者的故事，战士和法师（原本是对立阵营的两人，在失足落下地牢后，决定舍弃之前的偏见，合作逃出可怕的地牢）
- [ ] 魔法师德利米亚战士巴莱德
- [ ] 此时正好是魔法学派独立运动的高潮，两人在一场战斗后，失足落下一个地牢(游戏场景)，这个地牢里栖息着植物系魔物和昆虫系魔物，以及爬行系魔物


## 游戏的两个角色的角色性能

- [ ] 战士: 战士可以进行近战攻击，有更多的可行动作，防御力也更高
- [ ] 魔法师: 会魔法，且会远程的攻击，可以给战士的武器进行附魔，但是近战的能力较低
- [ ] 讨厌做AI就干脆少做，纯双人
- [ ] 战士的主要: 近战攻击模组
- [ ] 魔法师的主要: 远程攻击的模组
- [ ] 敌人的主要: AI


## 游戏内出现的怪物

- [ ] 史莱姆
- [ ] 蜥蜴: 会伸长舌头对玩家进行攻击，或将周围的石子吞下，对玩家进行攻击
- [ ] 哥布林: 会进行人类的攻击
